# Proposal: Fix HvH Core Bugs, Movement, Anti-Aim Auto Adjust, Ragebot Moving Shots, and UI

## Problem
Live CS2 testing (`shogod-20261120.log`, `shogod-20261121.log`) and end-to-end M1–M4 code/UI audits identified core defects across Movement, Anti-Aim, Ragebot, Lag Compensation, UserCmd subtick handling, and UI:
1. **BunnyHop, Edge Jump, and AutoStrafe defects**: adding subtick release/press steps (`0.0f` false / `0.001f` true) every ground tick broke BunnyHop; `edge_jump` conflicted with active `bhop` when holding Space; `compute_autostrafe` used a suboptimal `24.4f` transverse dot target; `compute_quantized_autostrafe` stalled below `252 u/s`; `auto_pistol` and `peek_assist` timers advanced per render frame (~300 Hz) instead of per `command_number`.
2. **Anti-Aim coupling, 45-degree AA snapping, and missing bind**: `at_targets`, `base_yaw::off`, `freestanding`, and `auto_adjust` leaked state into each other; `align_aa_yaw_for_ground_move` snapped `aa_angles.yaw` to 45-degree camera sectors; `!on_move` flickered when `has_move_input` was active; `anti_aim_cfg::toggle` lacked `bound_feature::anti_aim` keybind sampling; `jitter` seeded on stalling `frame.tick`; and `freestanding` risked enemy-pawn self-hits.
3. **Ragebot, Lagcomp, Backtrack, AutoStop, and UserCmd defects**: premature head breaks skipped `eval_hc` and body scan; `arms` (`hitgroup 4,5`) aliased `pelvis` and `ignore_limbs` was unwired; `lagcomp` required missing `m_flOldSimulationTime` and `createmove` overwrote the middle `shooting` record; unconditional `+50ms` extrapolation and `render_tick_count + 1` desynced hitboxes; `backtrack_history` flooded 16 slots at 300 Hz and persisted across disconnects; `chance_multi` spilled body shots onto arms; `box` hitboxes used capsule approximations; `autostop` dropped braking on firing ticks, locked on `between_shots`, and ignored `auto_stop_speed`/`ticks`/`wait`; `remove_recoil`, `safe_point`, `strict_hitchance`, `resume_zoom`, `auto_revolver` `k_in_attack2` clearing, `cycle_cursor` fire-only advance, and `RepeatedPtrField`/`0x60u` subtick hygiene needed fixes.
4. **Input, Events & UI gaps**: `bind_state::sample` hold logic didn't refresh continuously, `Peek assist` and `Anti-Aim` binds needed `Settings -> Input` wiring, `shot_events.cpp` compared vtables against stale hardcoded RVAs, and `world.cpp` contained a duplicate helper block.

## Scope
- Fix BunnyHop via `step_bhop` per-`command_number` latch (`when = 0.0f` landing press, 1-tick ground release re-arm) and `edge_jump` arbitration when `bhop && jump_held`; fix AutoStrafe via `k_air_dot_target = 0.0f` AirAccelerate optimum (`F3.2`) and post-AA 45-degree sector-matched continuous AutoStrafe (`F3.1`, `|yaw_delta(ref_yaw, steer_yaw)| <= 22.5 deg`, zero spin); implement `Slide walk` (`leg_movement`) and `command_number`-latched `auto_pistol` / `peek_assist` timers; enforce `RepeatedPtrField` capacity/`nullptr` and `0x60u` `has_bits` hygiene (`F2.10`, `F3.3`).
- Unify Anti-Aim (`apply_antiaim_full`) with strict orthogonality across `at_targets`, `base_yaw` (`off` without hidden `+180`, `fake_static`, `jitter`, `random`), `freestanding` (`freestanding_head_probe`, `freestanding_trace_target`, `select_freestanding_yaw`), `auto_adjust` (`pose_head_yaw_offset` weapon/pitch aware across modes), `yaw_offset`, `bound_feature::anti_aim`, deterministic `command_number` jitter seed, `speed_2d <= 5.0f && !has_move_input` on `!on_move`, and `compute_quantized_ground_move` (`{-1,0,+1}` 2D error diffusion preserving arbitrary `aa_angles.yaw` instead of 45-degree AA-yaw snapping) plus `rotate_move_inputs` + `sync_move_held_buttons` on fire ticks.
- Harden Ragebot, Lagcomp, Backtrack, HitboxGeom, Hitchance, and AutoStop (`F1.1`–`F1.17`): post-`eval_hc` break + `prefer_body_aim`, `arms=5` vs `pelvis=3` + `ignore_limbs`, `last_shot_time` on-shot lagcomp + 3-record `[newest, shooting, oldest]` retention, lag-gap-only extrapolation + aligned `render_tick_count`, 300 Hz backtrack dedup + disconnect reset, `sv_maxunlag` window check, `chance_multi` torso isolation + `safe_point`/`strict_hitchance`, OBB box geometry + `hitboxes.cpp` Fallback #2, firing-tick AutoStop hold + `auto_stop_speed`/`ticks`/`wait` + `is_between_shots_window`, `remove_recoil`, `auto_scope` `resume_zoom`/unscoped HC, `auto_revolver` `k_in_attack2` clear, `range`/helmet/shotgun/`imp.hitgroup` fixes, `cycle_cursor` advance on fire, Zeus `pistol` mapping, and `command_number` scan caching.
- Fix `bind_state::sample` hold handling, wire `Peek assist` and `Anti-Aim` binds in `Settings` and `Keybinds`, remove stale hardcoded RVAs in `shot_events.cpp`, remove duplicate helpers in `world.cpp`, and balance `RageBot` / `Anti-Aim` UI cards cleanly.
